Schematic of Circuit


I chose to make a circuit with 3 LEDs - 2 red and one yellow - in parallel with each LED connected to its own 330 ohms resistor. I chose 330 ohm resistors to get the current to approximately 10 mA each. Since I was connecting 3 LEDs in parallel combination, the current would have added up. So, in order to keep the current less than 40 mA, I chose 330 ohms as the safest option. The caluclations are attached below.

Arduino Code Snippet


void setup() {
// Set digital pin 4 as an output to control the first LED.
pinMode(4, OUTPUT);
// Set digital pin 3 as an output to control the second LED.
pinMode(3, OUTPUT);
// Set digital pin 2 as an output to control the third LED.
pinMode(2, OUTPUT);
}

// The loop function repeats the blinking pattern continuously.
void loop() {
// Turn on the first LED connected to pin 4.
digitalWrite(4, HIGH);
// Turn off the second LED connected to pin 3.
digitalWrite(3, LOW);
// Turn on the third LED connected to pin 2.
digitalWrite(2, HIGH);
// Keep this LED combination for 1 second.
delay(1000);

// Turn off the first LED connected to pin 4.
digitalWrite(4, LOW);
// Turn on the second LED connected to pin 3.
digitalWrite(3, HIGH);
// Turn off the third LED connected to pin 2.
digitalWrite(2, LOW);
// Keep this LED combination for 1 second.
delay(1000);

// Keep the first LED turned off.
digitalWrite(4, LOW);
// Keep the second LED turned off.
digitalWrite(3, LOW);
// Turn on the third LED connected to pin 2.
digitalWrite(2, HIGH);
// Keep this LED combination for 1 second.
delay(1000);
}

Question 2: How many LEDs can you independently blink, and how much current does each LED use?
I can independently control all three LEDs because each LED is connected to a separate digital pin on the Arduino: pins 2, 3, and 4. Each LED has its own 330 Ω resistor to limit the current. Assuming a 5 V supply and a 2 V voltage drop across each LED, the current through each LED is calculated using Ohm’s law:
Current = (5 V − 2 V) / 330 Ω = 0.0091 A ≈ 9.1 mA per LED.
If all three LEDs are on at the same time, their combined current is approximately 27.3 mA.

Question 3: At what blinking frequency does the LED appear to be continuously on?
I observed that the LEDs appeared nearly continuous when blinking at approximately 50–60 flashes per second, with intervals of around 17–20 milliseconds between flashes. At this speed, the human eye has difficulty distinguishing individual flashes, making the light appear steady.
